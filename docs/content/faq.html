--- title: FAQ description: Short answers to the questions people ask most about Mossnote, based on how it actually works. ---

The basics

Can Mossnote spoil a game for me?

No. It ships with no information about any game: no names, items, places or mechanics. A new journal is empty and everything in it is something you wrote. Even the Stardew Valley template carries only wording and a calendar. See What a template never contains.

Does it need the internet?

The computer version never uses the network, except locally between your computer and a phone you paired. The web version needs a connection only to load the page the first time (and to check for a newer copy of the app when you open it); after that it works offline. Neither sends your notes anywhere.

Do I need an account?

No. There are no accounts, analytics, crash reports or update checks.

Is it free? What is the licence?

It is MIT-licensed open source. Its fonts are under the SIL Open Font Licence and the web version bundles SQLite WebAssembly (Apache-2.0).

Has it been released?

Not yet. Until the first release you run it from the source code (how), or use the web version if the project owner has published it.

Your data

Where are my notes stored?

Computer version: one file per journal in your user folder. Web version: in that browser's storage. See Where your journal lives.

Can I sync between my computer and my phone?

There is no sync. Two options: phone access lets a phone write into the journal that lives on your computer; or export and import a JSON file to move a journal. A journal on a computer and a journal in a browser are separate.

How do I back up?

Use Export JSON and keep the file somewhere safe. Mossnote also keeps snapshots you can restore. In the web version, backing up matters most: clearing the browser's data deletes the journal.

Is my journal encrypted?

No. It is a plain SQLite file (or browser storage). Use your system's disk encryption.

I deleted something. Can I get it back?

Notes, people, farm entries and maps stay in Recently deleted for 30 days. A deleted note also shows an Undo message. A deleted journal is gone unless you kept its last copy or downloaded it.

Can I open my notes without Mossnote?

Yes. The Markdown export is plain text, and the JSON export is documented in Export format. The computer version's journal is an ordinary SQLite database.

Using it

What is the difference between the Default and Stardew Valley templates?

Stardew Valley adds a Farm section, a calendar of seasons, four quick actions and different names for two sections. Everything else is the same. Comparison table.

Can I change a journal's template later?

No. A journal keeps its template. Make a new journal with the other one and move your notes with an export and import (see Troubleshooting).

My game isn't listed. What do I do?

Use Default. You can rename and hide sections, so it can read the way you like. The template picker links to a form to request a template.

What is a discovery, and what is a question?

Two flags you put on notes: ✦ for something you found out, ? for something you want to find out. A question can later be marked solved with your own answer. See Questions and discoveries.

What does “Set date” do, and do I have to?

It tells Mossnote which in-game day you are on so notes can be grouped by it. You do not have to. Undated notes work fine and you can add dates later. See Dates and the calendar.

Why did my @name or #tag stay as text?

Only choosing from the list that opens as you type creates a person or tag. See Troubleshooting.

Can I add pictures to notes or maps?

No. Images in notes and imported images on maps are left out on purpose. You can draw on maps and export them as pictures.

Can I use it on a phone?

Yes, two ways: the web version in the phone's browser (the journal is kept on the phone), or phone access to a journal on your computer. The layout adapts with a bottom bar.

Does it work with a keyboard only?

Yes. See Keyboard shortcuts. Press ? outside a text box.

How many notes can I have?

The app sets no limit on the number of notes. Individual items have size limits; see Limits. We did not test very large journals.

How do I search for notes on a certain day?

Type day 12 (Default) or spring 3 (seasons) in the search window, or choose the day's heading in the Journal. See Search syntax.

Maps

Why did my freehand shape change?

Tidy-up drawing turned it into a clean shape. Choose Keep my drawing, or turn it off in View.

How do I put a note on a map?

Drop a marker and link it to a note (or write a new note from the marker's panel). The note then lists the marker under On maps. Or place a sticky note on the map itself with the Note tool.

Can I move a map to another journal?

Yes. Export it as an Editable project file and use Open a map file in the other journal.

The project

How do I report a bug or suggest a feature?

Open an issue on the project's GitHub page. Please do not paste your notes into it.

Will you add feature X?

The README lists features the project has decided against: image attachments, imported map images, tag colours, checklists, completion tracking, cloud sync, accounts, rich text, statistics, AI features and plugins. Requests for those will be closed. Other ideas are welcome as issues.

How can I contribute a template?

A template is a small file of wording and structure. Read the project's CONTRIBUTING guide first, and never add game-specific facts.
