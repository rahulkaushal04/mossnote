--- title: Getting started description: Open Mossnote on a computer or in a browser, choose a template, and write your first note. ---

What Mossnote is

Mossnote is a private journal for the games you play. You write what you discover, who you meet and what you wonder about. It knows nothing about any game: there are no names, items, places or mechanics built in, so a new journal is empty and nothing can be spoiled. It has no accounts, no analytics and no sync. Your notes stay on your own device unless you export a file yourself.

Choose how to run it

The same app comes in two forms. They look and behave the same, apart from the differences listed in the table.

The two versions of Mossnote
You play onUseYour journal is kept
A PC or laptop, with notes on the same machineThe computer version (runs from Node or as a downloaded program)In a folder on the computer
A PC or laptop, with notes on a phone or tabletThe computer version with phone access turned onIn a folder on the computer
A console, with notes on a phoneThe web version on the phoneIn the phone's browser

A journal kept on a computer and one kept in a browser are separate. To move one, export it from one side and import the file on the other.

Open the web version

The web version is a website with the journal built into the page. Open the address where it is published (the Open Mossnote button at the top of these pages goes there). Use an up-to-date Safari, Chrome, Edge or Firefox in a normal, not private, window. Nothing is installed and nothing is uploaded. Read more about the web version.

Install the computer version

Mossnote has not had a public release. Until it does, run it from the source code. The npx and download routes below will work once the first release is published.
  1. From source (works today). You need Node.js 22.12 or newer. In a terminal: 
    git clone https://github.com/rahulkaushal04/mossnote.git
cd mossnote
npm install
npm start
    npm start builds the app if needed, starts it and opens your browser at http://127.0.0.1:4317.
  2. With Node, once released. npx mossnote to try it, or npm install -g mossnote and then mossnote.
  3. As a program, once released. Download the Windows .exe or the Linux .tar.gz from the releases page and run it. macOS users use the Node route.

Run mossnote --help for the options --port, --data-dir, --journal, --no-open and --lan. See Options.

Make your first journal

The first time you open Mossnote it asks one question: Which template?

The first screen. (1) Default template, (2) Stardew Valley template, (3) the journal's name, (4) the button that creates it.
  1. Pick a template. Default fits any game; Stardew Valley adds a Farm section and a calendar of seasons. A template only changes wording and structure, never facts about a game. See Templates. A journal keeps its template for good, so to use the other one later you make another journal.
  2. Type a name for the journal (up to 60 characters). Only you see it; it helps you tell journals apart.
  3. Choose Start my journal. You land on Today with the note box ready.

The same screen links to Request a template, which opens the project's feature-request form on GitHub in a new tab.

Write your first note

  1. Click in the note box on Today (it is already focused when the page opens) and type something you just found out.
  2. Press ⌘Enter (CtrlEnter on Windows and Linux), or choose Save.
  3. The note appears under the box at once, the box empties and stays focused, and the next note can follow straight away.

Your text is kept as a draft while you type, so a refresh or an interrupted connection does not lose it.

Tell it the in-game day

Choose Set date above the note box. With the Default template you type a day number (Day 12); with Stardew Valley you pick a year, a season and a day. Every note you save from then on is stamped with that date, and your journal groups notes by game day. You can skip this: notes without a date still work, and you can add dates later. See Dates and the calendar.
