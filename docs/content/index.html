--- title: Mossnote documentation description: Learn Mossnote, a private, spoiler-free journal for the games you play. Start with the basics or jump to the part you need. ---

Mossnote is a journal you keep while you play a game. You write down what you find out, in your own words, and Mossnote keeps it organised: by in-game day, by person, by tag, and on maps you draw yourself. It ships with no information about any game, so it can never spoil anything, and it never sends your notes anywhere.

Maps

A built-in drawing tool for the places you explore, with markers that link back to your notes. Start with the maps overview, then see the drawing tools, markers and exploring mode, and layers, history and export.

Templates and journals

Keep one journal per game. A template only changes wording and adds a few shortcuts. The Default template fits any game; the Stardew Valley template adds a Farm section, a calendar of seasons and quick actions.
