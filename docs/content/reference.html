Mossnote needs Node 22.12 or newer (22 up to 24). The web version has no options; its address base is set when it is built (MOSS_BASE).

Export format

Export JSON writes one JSON file. Its top level has these keys:

KeyHolds
format, formatVersionWhich kind of file, and its version (currently 1). A file with a newer version than the app can read is refused.
exportedAt, appWhen it was made, and the Mossnote version.
journalNameThe journal's name.
settingsCalendar, layout (template, sections), preferences and marker types.
tags, people, plantings, maps, notesYour records. They keep their identifiers, reference tags by name, and drop anything in Recently deleted.
  • Dates are written as { "year": 1, "season": 0, "day": 3 }; a note's date also gets the season's name for readability, which is ignored on import. In a day-counter journal "season" is always 0.
  • Import validates every field. It reports problems with their position in the file and changes nothing if there are any.

Export Markdown writes a readable document: # Mossnote, a line with the date and counts, then ## Journal (one ### heading per day, notes marked ✦ or ?), ## Not dated, ## Questions (### Open, ### Solved), ## People, ## Farm and ## Maps. Sections with nothing in them are left out.

A single map's Editable project file is a separate JSON file (.mossmap.json) that holds that map only.

Map building blocks

  • Marker icons (20): pin, dot, star, flag, question, exclamation, door, key, chest, person, house, tree, water, mountain, cross, eye, heart, diamond, bolt, cave.
  • Named colours (6): ink, moss, sky, rose, amber, plum, plus a custom colour. Named colours adapt to the light and dark themes; exports use fixed colours.
  • Line widths: 1, 2, 3, 5, 8, 14. Line styles: solid, dashed, dotted.
  • Text kinds: Text, Card, Callout, Sticky. Connector routes: straight, curved, elbow. Arrowheads: none, one end, both.
  • Suggested layers: Background, Terrain, Paths, Locations, Notes. Suggested marker types: Important, Question, Person, Treasure, Entrance, Blocked, Interesting.

Under the hood

  • Database: SQLite, one file per journal, with full-text search (FTS5) and automatic migrations.
  • Fonts: Inter and Literata, bundled; nothing is fetched.
  • Licence: MIT. SQLite WebAssembly in the web version is Apache-2.0.
