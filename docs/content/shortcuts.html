--- title: Keyboard shortcuts description: Every keyboard shortcut in Mossnote, grouped by where it works, and how to turn the single-key ones off. ---

Mossnote can be used entirely from the keyboard. Press ? outside a text box to see this list in the app, or find it in Settings → Shortcuts and about. Shortcuts that use ⌘ (Mac) use Ctrl on Windows and Linux.

A ✓ in the last column means we pressed the keys in the running app and saw the result. Without it, the shortcut comes from the source code and the app's own list, and we did not press it.

The one-key shortcuts (n, g, d, /, ? and the rest) are ignored while the cursor is in a text box, in a dialog or menu, or when ⌘, Ctrl or Alt is held. That includes Today's note box, which is focused when the page opens: press Esc (it leaves the box and keeps your draft) before using them. We also found that ⌘K is ignored inside a text box, even though the app's list says it works everywhere.

Turning single-key shortcuts off

If a single key gets in your way, for example with a screen reader or voice control, untick Single-key shortcuts in Settings → Shortcuts and about. Shortcuts with ⌘ or Ctrl keep working. The choice is kept in this browser.

Notes on the key list

  • The in-app list shows g f only in journals that have a Farm section.
  • Keyboard hints such as ⌘Enter on buttons are hidden on touch screens; they are never the only way to do something.
  • Focus and tabbing. Focus outlines are never removed. Press Tab once on a new page to find the Skip to content link.
