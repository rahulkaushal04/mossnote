--- title: "Tutorial: map an area" description: Sketch a place, drop markers, link a marker to a note, explore in play, and export the result. ---

You will draw a small area, mark places in it, link a marker to a note so the two stay together, and export the map. About fifteen minutes. The names are made up. You need a journal; see Getting started.

1. Create the map

  1. Choose Maps in the sidebar.
  2. Type River valley in Name a new map (optional)…. Tick Start with layers if you like to keep terrain and notes apart.
  3. Choose Start drawing.

Expected: the map editor opens with a dotted canvas, the tool strip on the left and the side panel on the right. The status bar says Saved.

Step 1 happens here.

2. Draw the area

  1. Choose Box (or press R) and drag a rectangle for the cabin.
  2. Choose Circle (O) and drag a pond.
  3. Choose Area (Y), click four or five corners for a field, then press Enter.
  4. Choose Draw (B) and sketch a rough rectangle by hand. When you let go it snaps to a clean box and says Tidied up as rectangle. Choose Keep my drawing if you prefer your wobbly one.
  5. Choose Text (T), click near the cabin, type Cabin and press Enter.
What drawing looks like.

Expected: each shape appears where you drew it, and you are back on the Select tool after each one. ⌘Z undoes the last step if you made a mistake.

3. Mark places

  1. Choose Marker (K) and click the cabin's door. Type Cabin door and press Enter.
  2. Click the pond's edge, type Fishing spot, press Enter.
  3. Choose Select (V), click the Fishing spot marker and choose Details… in the quick bar.
  4. Pick the star icon, type to check as the Status and add the tag fishing.
The marker panel. (1) Icon, (2) status, (3) link field.

4. Link a marker to a note

  1. In the marker panel, click the Link to a note, … field and type The best fishing spot is by the pond.
  2. Choose Save “The best fishing spot…” as a new note and link it.
  3. Choose Done.

Expected: the marker panel shows Linked to The best fishing spot is by the pond. In the Journal there is a new note with that text. Open it: under On maps it lists Fishing spot · River valley, and choosing it takes you back to the marker.

Writing the note from the marker panel.

5. Try exploring mode

When you are playing and do not want to hunt for tools, use Explore.

  1. Choose Explore (or press E).
  2. Tap the map to drop a marker, type its name, press Enter.
  3. Choose Path and draw the way you went. It starts from your last marker.
  4. Choose Note, tap the map and type; ⌘Enter finishes the note.
  5. Choose Done to leave exploring mode.
Exploring mode in use.

6. Tidy up

  • Open the Layers tab to hide or lock groups of objects. See Layers.
  • Turn on View → Grid and Rulers and guides, and use Measure with your own units. See Measuring.
  • Select several objects and use Align and Space across in Details.

7. Save a history point and export

  1. Choose History, type first draft and choose Save version.
  2. Choose Export and pick Picture (PNG) to share a picture, or Editable project file to keep the map itself.

Expected: a file named after the map (River valley.png or River valley.mossmap.json) downloads. You can open the project file later with Open a map file on the Maps page.

The Export menu.

8. Find it again

Back on the Maps page, Places lists every marker. Search for fishing and the marker, its note and the tag all turn up. See Finding markers again.
